# Publish checklist — Nomore Real Estate

Use before promoting a real listing (replace demos).

## Content
- [ ] Photos: cover + ≥6 gallery (landscape + detail)
- [ ] Optional vertical video / Reels link
- [ ] Titles & descriptions in **bg / ru / ua / en**
- [ ] Price EUR, area m², rooms, floor, act (if sale)
- [ ] Features tags + beach minutes
- [ ] Location id from `locations.ts`
- [ ] Status: `published` (not `draft`)
- [ ] Remove `demo: true` for real inventory

## Legal / trust
- [ ] Owner consent for publish
- [ ] No private docs in public gallery
- [ ] Privacy page still accurate

## Lead path
- [ ] WhatsApp deep-link tested from listing
- [ ] Viewing slots note (if needed)
- [ ] Telegram bot wired (when token available)

## SEO
- [ ] Unique slug
- [ ] OG image (listing cover or brand OG)
- [ ] Sitemap regenerated / redeployed
