# ТЗ: Nomore Real Estate

Статус: чернетка на узгодження  
Бренд: **Nomore Real Estate**  
Ринок: область Бургас + узбережжя (у т.ч. Сонячний Берег)  
Мови: BG · RU · UA · EN  
Послуги: купівля/продаж + оренда  
Контент об’єктів на старті: немає → спочатку лендінг + ліди

---

## 1. Позиціонування

**Хто:** ріелторське агентство в Бургасі та по області.

**Чим відрізняється (тихо):**
- чистий сучасний сайт (швидкий, мобільний);
- зрозуміла подача об’єктів (коли з’являться);
- швидка відповідь у WhatsApp / Telegram;
- чесна комунікація без «люкс-пафосу» і без «медіа-агентства».

**Одне речення:**  
Nomore Real Estate допомагає купити, продати й орендувати житло в Бургасі та на узбережжі — просто, сучасно і по суті.

**Слоган (робочий, на вибір):**
- EN: Property in Burgas, done properly
- UA: Нерухомість у Бургасі — просто і по суті
- BG: Имоти в Бургас — ясно и коректно
- RU: Недвижимость в Бургасе — просто и по делу

## 3. Візуальний стиль

**Напрямок:** світлий coastal / Mediterranean office — не dark luxury, не «Apple landing», не газетний layout.

- Фон: теплий off-white / пісок + легкі градієнти моря
- Акцент: один — глибокий морський синій *або* приглушений теракота/пісок
- Шрифти: сучасний grotesk + один характерний display для заголовків (не Inter/Roboto/Arial)
- Багато повітря, великі фото, мало декору
- Відео — опція на сторінці об’єкта / пізніше в hero; не обов’язковий cinematic loop на старті
- Hero: бренд + 1 headline + 1 речення + CTA-група + один візуальний якір

## 4. Географія

Область Бургас і курортна зона, зокрема:
- Бургас (місто + райони)
- Сонячний Берег (Слънчев бряг)
- Несебр, Равда, Поморіє
- Созополь, Святий Влас, інші релевантні локації округу

У фільтрах каталогу — групами/списком локацій (не «весь світ»).

## 5. Фази продукту

### Фаза 0 — зараз (без об’єктів)
1. Coming soon / бренд-лендінг
2. Мовний перемикач BG / RU / UA / EN
3. Коротко: хто ви, зона роботи, купівля+оренда
4. Дві форми:
   - «Шукаю житло» (тип, бюджет, локація, контакт)
   - «Хочу продати / здати» (тип, район, контакт)
5. WhatsApp + Telegram (плаваюча кнопка або чіткі CTA)
6. Сповіщення лідів у Telegram-бот

### Фаза 1 — каталог
- Каталог з фільтрами: купити/орендувати · тип · локація · бюджет · кімнати
- Картки + сторінка об’єкта (галерея, факти, опис, опційне відео, CTA)
- Адмінка або простий CMS для додавання об’єктів (окреме рішення в імплементації)

### Фаза 2 — контент і довіра
- FAQ / гід: Акт 14/15/16, покупка для іноземця
- Про нас (коротко)
- Опційна інтеграція коротких відео до об’єктів

## 6. Структура сайту (цільова)

| Сторінка | Фаза | Зміст |
|----------|------|--------|
| `/` Головна | 0 | Hero, послуги, зона, CTA, форми/лід |
| `/buy` або каталог `?deal=sale` | 1 | Продаж |
| `/rent` або `?deal=rent` | 1 | Оренда |

| `/sell` | 0–1 | Для власників |

i18n: префікс локалі — `/bg`, `/ru`, `/ua`, `/en` (або cookie + префікс; деталі в імплементації).

## 7. Форми (Фаза 0)

### Шукаю житло
- Ім’я
- Телефон / WhatsApp / Telegram
- Купити або орендувати
- Тип (апартамент, будинок, інше)
- Локація (мультивибір або «будь-яка»)
- Бюджет (від–до, опційно)
- Коментар

### Хочу продати / здати
- Ім’я
- Контакт
- Продаж / оренда
- Тип + район
- Короткий опис
- (опційно) посилання на фото

Після сабміту: подяка + миттєве повідомлення в Telegram власника.

## 8. Tech (орієнтир)

- Next.js (App Router) + TypeScript + Tailwind
- Static-friendly де можливо; форми через API route / serverless
- Telegram Bot API для лідів
- Деплой: Vercel
- Зображення: WebP/AVIF, lazy load
- Mobile-first

Не на старті: особистий кабінет клієнта, складна CRM, live Reels-фід, dark cinematic theme.

---

## 9. Контент, якого ще немає

Поки немає реальних об’єктів:
- не показувати фейковий каталог;
- акцент на бренд, зону, послуги, швидкий контакт;
- у соцмережах вести на лендінг / форму.

Коли з’являться перші 3–6 об’єктів — відкрити каталог.
