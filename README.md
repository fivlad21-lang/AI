# Pokémon CEO Birthday Quest

Интерактивная веб-открытка в стиле **Pokémon / Game Boy Color** с пасхалками Cicada 3301.

## Запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000).

## Вкладки

| Tab | Описание |
|-----|----------|
| 🏠 HUB | Офис + Taycan + 4 покемона с диалогами |
| ⚔️ BATTLE | Бой против CEO Пикачу |
| 🎴 POKÉDEX | Досье команды |
| 🌐 3301 | Секретный терминал Cicada |

## Пасхалки

- В футере: `3301: Welcome. Epiphany is upon you.` / цикада
- `F12` → ASCII цикады + binary `CEO3301` в console
- На клавиатуре набери **3301** → Protocol в бою
- **Master Ball** внизу → confetti + поздравление
